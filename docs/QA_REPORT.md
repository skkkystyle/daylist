## Найдено и исправлено

Текст выполненных задач имел контраст 3,81:1 на белом фоне. Автоматическая
проверка требует минимум 4,5:1 для такого текста. Вместо `#788399` используется
общий вторичный цвет `#65718a`, дающий около 4,90:1. Галочка и зачёркивание
сохраняют различие между выполненными и активными задачами.

Изменение находится локально. Для включения в GitHub и публичную версию
потребуется отдельное обновление соответствующих исходников и сборки.
