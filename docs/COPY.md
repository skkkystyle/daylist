# Тексты интерфейса

Для правки использован открытый навык
[ux-copy](https://github.com/vadimdemidov/redaktura-ru-skills/tree/main/ux-copy).
Навык прочитан и применён к интерфейсу, глобально не устанавливался.

Контекст: пользователь видит список, добавляет дела и отмечает выполненные.
Тон: спокойный, дружелюбный, обращение на «ты».

| Было | Стало | Правило |
| --- | --- | --- |
| Большие дела начинаются с маленьких | Пока нет задач | Заголовок называет состояние |
| Не обязательно успеть всё. Начни с одного дела. | Добавь первую задачу в поле ниже. | Событие и шаг |
| Каждая галочка — маленькая победа | Выполнено X из Y | Заголовок называет состояние |
| Выполнено X из Y. Двигайся в своём темпе. | Отмечай задачи по мере выполнения. | Слова пользователя |
| Все планы стали делами! | Все задачи выполнены | Заголовок называет состояние |
| Хорошая работа. Теперь время для себя. | Можно добавить новую задачу. | Событие и шаг |
| Одно дело или большой план — начни с первой строки. | Напиши задачу и нажми «Добавить». | Событие и шаг |

Фактическое количество выполненных задач вычисляется из списка. Подсказки
описывают существующие действия; новые возможности или сроки не обещаются.
