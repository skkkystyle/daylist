# Дизайн Daylist

Направление из брифа: дружелюбный светлый минимализм, один синий акцент,
центральный список, мягкие скругления и короткая обратная связь на действия.

Использован [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill):
поиск дизайн-системы для productivity web application и рекомендаций React.
Из выдачи применены плоские поверхности, простые SVG-иконки, стабильные ключи
элементов списка, управляемый ввод, видимый фокус, адаптивность и поддержка
`prefers-reduced-motion`.

Подборщик предложил структуру лендинга с демонстрацией продукта. Она не подходит
списку задач, поэтому композиция следует брифу. Палитра и шрифт выбраны вручную:

- Акцент: `#4465e8`, наведение: `#3654cd`.
- Фон: `#f6f8fc`, поверхность: `#ffffff`.
- Основной текст: `#26324b`, вторичный: `#65718a`.
- Шрифт: Manrope Variable, включая кириллицу, с локальной раздачей через Fontsource.
- Размер центральной области: до 800 px, адаптивные поля на телефоне.

Исходное состояние пустое. Предложения задач добавляются только по нажатию
пользователя. Демонстрационные данные используются лишь в тестах и скриншотах.
